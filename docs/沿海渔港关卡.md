# 沿海渔港灾后巡查关卡

这是一个灾后退水阶段的合成渔港。巡查区域沿 UE 世界 X 和 Y 均为 −1,000 至 +1,000 米。负 Y 一侧是海，正 Y 一侧是镇区，西侧为码头、东侧为泥滩。活动区外保留宽度随岸线与山坡变化的缓冲带，地形和海面沿同一条不规则外轮廓收边。地图使用本地坐标，GPS 锚点只供模拟传感器使用。

## 打开关卡

Windows 上双击 [OpenCoastalHarbor.cmd](</mnt/d/Program Files/Epic Games/Project_5.2/project_520/OpenCoastalHarbor.cmd>) 即可启动 UE 5.2 并打开地图。已打开工程时，在内容浏览器进入 `Content/CoastalHarbor/Maps`，双击 `CoastalHarbor`。在 World Outliner 搜索编号，例如 `Vessel_035`，选中后按 **F** 即可查看该船。[UE 工程](</mnt/d/Program Files/Epic Games/Project_5.2/project_520/project_520.uproject>) · [关卡文件](</mnt/d/Program Files/Epic Games/Project_5.2/project_520/Content/CoastalHarbor/Maps/CoastalHarbor.umap>)

## 镇区与港区

从海上进镇，先经过防波堤和栈桥，岸上是工作码头、装卸路、仓库和鱼市。住宅退到港后，从谷地、山脊和果园路口向两侧分布，街区之间穿插田地和树带。31 条相连道路串起 362 个建筑地块，任务区最北 250 米有 77 个地块。290 栋住宅集中在五个住宅片区，沿既有道路排成 55 排，每排三至八栋，临街退让约 5 米。近岸与内陆按用途分布，街道与地块为合成布局，港镇关系参考英国纽林。[整镇俯视](../runs/scenes/20261124-irregular-districts/views/after.jpg) · [港区近景](../runs/scenes/20261124-inland-town/after/quay.png) · [住宅街面](../runs/scenes/20261124-irregular-districts/views/street.png) · [纽林社区规划](https://www.pznp.co.uk/wp-content/uploads/2023/11/PZNP-Submission-Plan-13-11-23-v2.9.pdf)

地表最宽约 2.61 km，南北跨度约 2.60 km，轮廓内面积约 5.42 km²。2 km × 2 km 活动区全部位于轮廓内。道路和田块在外边缘截止，轮廓内共有 655 棵树。水位为世界 Z = −2.65 米，陆地外缘以岩质侧壁封至 Z = −6 米。[全景实拍](../runs/scenes/20261124-irregular-districts/views/after.jpg) · [边缘探针](../runs/scenes/20261124-irregular-districts/edge-check.json)

220 栋环境住宅和 22 间环境店铺位于 `Harbor/StreetFrontages`。下表的 120 栋建筑有稳定的巡查编号。码头集散棚、庭院工具棚等属于环境物件。做指定目标复查时使用对象表里的当前坐标；制作全图建筑检测数据时需补标环境建筑。[住宅排布核验](../runs/scenes/20261124-irregular-districts/measurements.json) · [重载核验](../runs/scenes/20261124-irregular-districts/scene-check.json)

关卡的全域后处理体积和渔港 RGB 相机使用相同的固定 EV100（1.25），曝光补偿为 +1，RGB 输出伽马为 2.2。渔港后处理体积将动态全局光照方法设为 None，天空光强度为 0.80，海雾密度为 0.0065。编辑器透视视口使用 **Game Settings** 时跟随关卡曝光。巡查机位保存在米制 UE 世界坐标系中。[相机配置](../configs/simulation/robot_coastal_harbor_sensors.jsonc) · [鱼市观察位](../data/metadata/coastal_harbor/market-stations.json)

## 单机取图

在 Windows UE 中打开本关并点击 **Play**。下面的检查连接运行中的 ProjectAirSim，加载渔港单机配置，将一架无人机摆到固定观察点，保存三组递增时间戳及最后一组 RGB 和米制深度。默认机位看搁浅船只。`--view fish-market` 通过高处中转将相机摆到鱼市门前，核对相机位置与画面中心深度。运行前选择空的输出目录。此入口会重新加载当前模拟任务。

```bash
conda activate airsim
python src/scene_build/check_harbor_camera.py --address 172.21.192.1 --out runs/scenes/harbor-camera-check
```

地址是此次 WSL 实测的 Windows 网关。换机器时按实际仿真主机地址传参。[单机配置](../configs/simulation/scene_coastal_harbor.jsonc) · [相机验证记录](../runs/scenes/20261123-coastal-harbor/simulation/check.json)

## 场景与素材

UE 原生关卡保存对象、变换和环境。场景的自制网格、民用模型、材质及纹理在 `Content/CoastalHarbor`，场景也引用同一工程中的 `ModernCityBundle`、`Airport`、`MilitaryAirport` 和 ProjectAirSim 内容。跨机器搬迁可从内容浏览器右键关卡，执行 **Asset Actions → Migrate** 并包含引用依赖，目标工程需要对应的 ProjectAirSim 插件。

原始下载、纹理和导入网格随 Windows 工程保存在 `SourceArt/CoastalHarbor`。公开外部素材使用 tevy 的民用车辆、船只和建筑，Innerscene 的渔船，以及 Poly Haven 的实拍天空光照。来源表逐项列出下载地址、许可和 SHA-256。为模拟风灾制作的网格变体与完好原型共享基础外观。源文件保留了这些变体的制作方法。[来源表](../src/scene_build/source_assets.json) · [建模脚本](../src/scene_build/) · [原始素材](</mnt/d/Program Files/Epic Games/Project_5.2/project_520/SourceArt/CoastalHarbor>)

本关用于静态灾后外观取证。风力、冲击、浮力及结构承载能力没有做物理标定。对象标签不能用于推定一栋真实建筑是否安全，也不能直接作为真实灾害严重程度分级。

如需复核构建过程，几何源和纹理目录为 `meshes/`、`library/`、`terrain/`。原始 GLB 可由 `unpack_harbor_library.cjs` 解出，使用 meshoptimizer 0.25.0 和 basis_universal 1.16.4-1。Blender 3.6 的导出脚本以米建模；UE 生成脚本以厘米摆放。空工程副本中的 UE 阶段依次为 `harbor_import`、`harbor_level`、`harbor_library_import`、`harbor_finish`、`harbor_detail`、`harbor_landscape`，脚本运行时与上述素材目录并列。已保存的关卡可以直接使用。

街区建模使用 `harbor_street_meshes.py`，Blender 的输出目录为 `SourceArt/CoastalHarbor/streets`。该目录的 `Ground` 子目录保存实拍草地和碎石的底色、法线图。UE 阶段在 `harbor_landscape.py` 后执行 `harbor_streets.py`。运行 `harbor_review.py` 时将 `catalog.json` 和 `street-cameras.json` 与脚本放在一起。地块布局和风损外观均为合成。[地表纹理来源与校验值](../src/scene_build/source_assets.json) · [复拍机位](../runs/scenes/20261124-coastal-streets/street-cameras.json)

当前路网由 `harbor_port_inventory.py` 记录上一阶段 Actor 的尺寸和编号，`harbor_port_plan.py` 在 airsim 环境（SciPy 1.15.3、Shapely 2.1.2、GEOS 3.13.1）中读取该目录的 `inventory.json` 生成地块和三角网。Blender 运行 `harbor_port_meshes.py -- geometry.json 输出目录` 后，UE 运行 `harbor_port.py`，将地形、道路、地块和植被写入地图。如果已导入同名网格而 FBX 几何已变，在 UE 脚本工作目录创建空文件 `refresh-geometry` 以重新导入。`PortTown` 源素材目录中保存了 FBX、地块计划、原始尺寸和观察位。复验时把 `plan.json`、`catalog.json`、`parcel-check.json`、`market-stations.json` 和两个取图脚本放在同一工作目录。[Windows 源素材](</mnt/d/Program Files/Epic Games/Project_5.2/project_520/SourceArt/CoastalHarbor/PortTown>) · [主视口连续移动复核](../runs/scenes/20261124-inland-town/traverse/route.json)

港务办公楼和自卸车的完好版、风损版从同一套基础网格导出。运行 `harbor_library_fbx.py` 时，把 `harbor_office_cladding.py` 放在脚本旁边。办公楼先裁掉与包边重合的墙面或包边背面，再生成风损形变。自卸车两侧的加强筋端面埋入侧板 2 厘米。程序化商铺的中央橱窗在木门两侧各留一块玻璃。[修复近景对照](../runs/scenes/20261124-target-surface-repair/comparison.jpg)

重建风损时，在含 `plan.json`、`inventory.json` 和 `catalog.json` 的目录运行 `python harbor_storm_plan.py <目录>`。用 Blender 3.6 执行 `harbor_storm_meshes.py -- <FBX输出目录> <原模型library目录>`，关联的两个建模模块放在脚本旁。把 FBX 和 `wind-layout.json` 放到工程的 `SourceArt/CoastalHarbor/StormAftermath`，完整打开 CoastalHarbor 地图后，在 UE 编辑器 Python 环境调用 `harbor_storm_apply.apply()`。该步骤为新网格绑定材质，写入关卡，更新 Windows 编号表和散落物坐标；将复核过的编号表同步到研究仓库。已安装的地图可直接打开。[风损建模脚本](../src/scene_build/harbor_storm_meshes.py) · [UE 写入脚本](../src/scene_build/harbor_storm_apply.py)
